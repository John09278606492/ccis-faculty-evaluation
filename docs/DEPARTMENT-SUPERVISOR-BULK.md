# Fill missing supervisor assignments

In **Departments → Edit**, select the **Dean / Department Head**. Changing that
selection enables **Fill missing class supervisors when saving**. Choose the
academic period and save. The assignment runs in the background and sends a bell
notification when complete. For an already saved supervisor, enable the same
switch and save to apply it to the selected period.

In **Evaluations → Manage**, **Use Department Supervisor** fills missing choices
only for the teaching classes included in that evaluation. The same button is
available inside **Review & Open**. Wait for the completion notification, then
review again.

Both paths keep existing supervisor assignments, including multiple supervisors
and supervisors from other departments. They skip closed/archived evaluations,
inactive classes, Annex B task rows, other campuses and self-evaluation. A change
to department leadership while a task is queued invalidates that task; repeat the
bulk action using the current saved supervisor.

**Teaching Classes → Edit → Supervisors** remains available for individual changes.
Use it to select a different supervisor for a faculty member, or to add one or
more supervisors. The bulk action does not overwrite those selections. Changing
department leadership alone through an import or model update grants no evaluation
authority; the explicit bulk action creates the faculty-specific assignments.
